# Gluplandia Launcher 1.1.1

Esta revisión simplifica la pantalla Aventura y corrige la interacción principal.

- Se elimina la franja superior de anuncios de la interfaz.
- Se elimina la sección Crónicas de Gluplandia de la pantalla principal.
- Se ocultan ping y MOTD del panel del servidor; se conserva estado, jugadores e IP.
- El botón JUGAR A GLUPLANDIA mantiene su identidad naranja al pasar el cursor y gana un brillo cálido, barrido de luz y respuesta de espada.
- La estrella del botón Jugar se sustituye por un icono de espada vectorial.
- El rostro de la skin aparece en la tarjeta de identidad. Para Microsoft se usa el UUID cuando esté disponible; para perfiles locales se intenta resolver el nombre público. Si no existe una skin pública se usa un avatar local de respaldo.
- La reparación manual se mueve a Mi equipo para mantener limpia la zona de lanzamiento.
- Los efectos dungeon v4 y la música ambiental vuelven incluidos dentro del patch, evitando instalaciones donde el código apuntaba a archivos de sonido que no habían sido copiados.
- No se añade modo seguro.

Validación: 21 pruebas automatizadas superadas y App.jsx analizado correctamente como JSX.
